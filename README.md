# 🎨 Comanda+ Frontend

Interface moderna com Next.js 14, Tailwind CSS e shadcn/ui

## 🚀 Início Rápido

```bash
npm install
npm run dev
```

Acesso: http://localhost:3000

## 📚 Documentação

- [Como Rodar Localmente](../RODAR-LOCALHOST.md)
- [Deploy Vercel](../DEPLOY-VERCEL-RAPIDO.md)

## 🏗️ Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui
- Sonner (Toasts)

## 🎯 Funcionalidades

- ✅ Login mockado (4 usuários)
- ✅ Dashboard com 5 mesas
- ✅ Design responsivo
- ✅ Dark mode ready
- ✅ Tailwind CSS

## 🌍 Deploy

```bash
vercel --prod
```

Live: https://frontend-comanda.vercel.app
